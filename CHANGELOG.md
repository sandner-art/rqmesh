# Changelog

This project follows [semantic versioning](https://semver.org/); before 1.0 the API may change in minor versions.

## 0.1.0 — unreleased

First public version, carved out of thirteen internal research rounds.

- Edge-ring simplification with 3-1 and gentle (4-2, 5-3, 6-4) strip transitions, QEM placement, symmetry, UVs.
- Isolation loops: openings, isolating rings, protected loops around eyes, mouths and selected regions.
- Pole fixing with refills, a trial cache (2.2x faster) and guarded isolation rings.
- Base-cage recovery for Catmull-Clark, simple, Loop and midpoint subdivision, with creases and UVs.
- Structure analysis and workflow recommendation.
- Scale-matched cross fields for sculpts, with automatic setting selection.
- NumPy-only operation (Blender's Python); SciPy used when available.
